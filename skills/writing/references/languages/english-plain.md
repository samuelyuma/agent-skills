# English for Public Readers

Read for public-facing English: UI copy, public-service notices, guides, forms, and help content. For developer-facing cleanup, use `english.md`.

> Adapted from [english-plain](https://gist.github.com/orepras/61f07724a6d02d3f319e3371867dad6a) by [orepras](https://github.com/orepras), revision `fdb3576` (11 November 2026). See `CREDITS.md` in the source repository for permission status and changes.

## Audience and Voice

- Address the reader as "you" and the organization as "we". Keep the choice consistent.
- Use singular "they" when gender is unknown.
- Write for readers who may use English as a second or third language, or run the text through a translation tool.
- Prefer literal wording. Avoid idioms: "touch base", "low-hanging fruit", "ballpark figure", "move the needle".
- Formal text can sound human. Avoid "kindly", "whereby", "herein", and "aforementioned" unless the document type requires them.

## Plain Word Choices

| Avoid | Use |
|---|---|
| utilize, leverage | use |
| facilitate, empower | help, allow |
| collaborate, synergize | work together |
| deliver, surface | make, provide, show |
| regarding, with respect to | about |
| in order to | to, so that |
| commence, initiate | start |
| finalize | finish |
| address, combat | fix, deal with |
| impact (as a verb) | affect |
| purchase | buy |
| demonstrate | show |
| require | need |

Avoid metaphors and clichés: ecosystem, hub, robust, deep dive, game-changer, seamless, unlock, journey, digital transformation. Keep them only when they name something specific.

## Sentence Patterns

- Use active voice and a clear subject: "You can change your password at any time." Not "Password changes can be performed at any time by the user."
- Keep sentences to 12 to 20 words, never more than 25.
- Split stacked clauses when the reader must backtrack.
- Prefer "Save changes?" over "Are you sure you wish to save the modifications that have been made?"

## Spelling and Capitalization

- Pick US or UK spelling for the whole product and stay consistent. Follow the project's existing choice.
- Use sentence case for headings, buttons, labels, and table headers. Capitalize proper nouns.
- Do not use all caps for emphasis.
- Avoid camelCase and run-together hashtags in prose. Capitalize each word in a hashtag (#PlainLanguage).

## Punctuation

- End complete sentences with a period, including full-sentence list items.
- Do not join two sentences with a comma.
- Use the serial comma when it prevents ambiguity.
- Use an exclamation mark only for warm success or celebration, never more than one.
- Use an em dash sparingly. Do not stack several in one paragraph.
- Use quotation marks for direct quotes and titles. Do not use italics for titles.
- Avoid semicolons in user-facing text.

## Numbers

- Use numerals for 10 and above, and for any number with a unit or in a data list. Spell out one to nine in running prose.
- Write the percent sign directly after the number: 50%.
- Put the currency symbol before the amount: $75, €50, Rp75.000. Match the reader's thousands and decimal separators, and never mix conventions in one document.
- Write large amounts in words when it helps: "$5 million", not "$5M" or "$5,000,000".
- Use "to" or "from... to" for ranges: "10 to 20 people". Avoid hyphens and en dashes; screen readers may read them as "minus".
- Add a comparison when the amount is too large to picture easily.

## Dates and Times

- Write "4 June 2026", without ordinals such as "4th".
- Write time as "10 a.m." or "10:30 a.m.", or use 24-hour time consistently if the audience expects it.
- Write a range as "10 a.m. to 11:30 a.m."
- State the time zone when readers may be in several: "10 a.m. WIB".
- Write "noon" and "midnight" instead of 12 a.m. or 12 p.m.

## English Public Copy Examples

| Before | After |
|---|---|
| "Are you sure you wish to save the modifications that have been made?" | "Save changes?" |
| "An unexpected system error has occurred. Kindly repeat the process." | "We couldn't send it. Please try again." |
| "Please ensure that all fields designated as mandatory have been completed." | "Fill in all required fields." |
| "Password changes can be performed at any time by the user." | "You can change your password at any time." |
| "Error 404: User not found." | "This email isn't registered. Try another email or sign up first." |
| "Operation completed successfully." | "Your profile is updated." |

## Readers Outside the Default

- Do not assume a big city, a high income, fast internet, a new phone, or a bank account.
- Use examples and names that reflect many backgrounds, not only Western or urban ones.
- Avoid references that depend on one culture: sports metaphors, holidays, seasons, local brands.
- For regional services, add a translation or note in the local language for urgent instructions.

## Self-Check

- Can a first-time reader act after one read?
- Is the actor named when it matters?
- Is the spelling variant consistent?
- Are number, currency, and date formats consistent?
- Does it read as natural English, not as a translation?
- Is any sentence a word-for-word translation from another language?
- Is the text safe for a reader in a difficult situation?
- Did shortening remove a subject or a connector?
